按中文的规矩排版 蜻蜓文档 TTWriter

这是 WordCraft 的中文发行版： 一份能编译、能跑、能改的完整源码，在上游之上补上中文写作真正需要的那一层—— 公文、学位论文、法务文书的国标版式，中文字数怎么算，字体怎么正确写进文件。

上游 WordCraft 由 ArtCraft 团队开发（MIT OR Apache-2.0）。本项目不是 ArtCraft，不代表 ArtCraft， 也不使用任何 ArtCraft 标识，仅以平文本说明「基于 WordCraft」。

01这是什么

不是插件，不是皮肤。一个仓库 clone 下来就能构建，里面就是 WordCraft 本体加一层中文。

完整源码

完整上游源码 + 补丁

与上游的分歧只有两处小补丁，都在小函数里。合并上游很容易，其余部分照上游原样保留。

字数

中文字数按字计

中文没有空格可切。原先把一段中文按空格分词统计，字数严重偏少；现在按 Word 的中文字数口径统计。

字体与语言

东亚字体与语言标记

w:rFonts/@w:eastAsia 与 w:lang/@w:eastAsia 正确读写。中文文档在 Word 里打开不掉字体、不掉语言标记。

排版层

国标排版技能与预设

公文 GB/T 9704、学位论文 GB/T 7713 与参考文献 GB/T 7714、法务文书，四套技能配四套预设，一次应用。

离线

不联网，不上传

没有账号，没有云同步，没有遥测。稿子留在你自己的机器上。

可被程序驱动

命令行、MCP、控制通道

每个功能都是命令。界面、快捷键、CLI、MCP 走同一套命令注册表，AI 助手也能安全地操作文档。

02中文排版层

技能是给 AI 助手用的操作手册：什么时候用哪条命令、国标要求什么、哪里会踩坑，每个技能都配了可直接运行的脚本。 技能只做排版——内容必须是已经定稿的文本，它不会替你写、编或改一个字。

技能干什么依据
gongwen公文：通知、请示、报告、函、纪要、批复、意见GB/T 9704—2012
thesis学位论文：封面、页眉、目录、图表编号、参考文献GB/T 7713.1、GB/T 7714—2015
legal-docs民事起诉状、律师函、法律意见书、合同审查报告，可出对外脱敏版法务文书惯例
wordcraftWordCraft 全部命令的用法、可用性核查与证据台账—

presets/ 下四套中文页面与默认样式，是一段可直接跑的脚本： 

wordcraft-cli run --file 稿子.docx --script presets/zh-gongwen.json --save out.docx

03相对上游迭代了什么

基线是上游 WordCraft v0.9.0。

已提交上游 · 1

中文字数按字统计

一段中文原来会被按空格切开数，字数严重偏少。现在按 Word 的中文字数口径（G2）统计，数字与字符也一并算清。

已提交上游 · 2

w:lang/@w:eastAsia 读写

中文段落之前会丢掉东亚语言标记，在 Word 里打开后拼写检查语言会跑成英语。

本发行版

修掉公文排版的字体名

现代 Windows 上并不存在 仿宋_GB2312 这个字体名，写了会静默回退成黑体，公文的仿宋 / 楷体区分整个丢掉。现在按候选顺序取真机上真实存在的字体名。

本发行版

修掉论文脚本的命令顺序

插入页眉会把光标移进页眉文本区，此后只能在正文执行的命令会失败。现在目录与著录排在前，页脚页眉排在后。

本发行版

换成自己的图标

移除全部 ArtCraft 图案，换成朱砂圆角方块加一个「文」，一个脚本生成 SVG / PNG / ICO / ICNS。

本发行版

薄发行版

crate 名、二进制名 wordcraft.exe、配置目录、包名都保持上游原样，方便与上游同步。不同的只有显示名：窗口标题、关于对话框、exe 属性、安装包条目，一共二十几行。

已知限制写在文档里，不藏着：

  • 没有中文拼写 / 语法校对。WordCraft 的校对只覆盖英、俄、波、葡、意几种语言，本发行版也没有假装有。
  • GB/T 7714 条目模板缺期号槽位，期刊论文的期号需要手工补。
  • 参考文献默认标题是英文 References，用 references.bibliography 的 title 参数改成「参考文献」。
  • 方正小标宋简体不是 Windows 自带字体，机器上没有时公文标题会回退为黑体并给出提示。
  • 简繁转换、拼音排序、按地区自动选默认样式还没做。

04装上试试

从源码构建，然后命令行、MCP 或直接开界面用。

git clone https://github.com/matou1118/ttwriter
cd ttwriter
cargo build --release -p wordcraft        # 需要 Rust 1.95+

wordcraft-cli convert 稿子.docx 稿子.pdf            # 转格式
wordcraft-cli render 稿子.docx page1.png --page 1   # 渲染成图
wordcraft-cli commands                              # 列出全部命令
wordcraft-cli mcp                                   # 以 MCP 服务器方式跑，交给 AI 用
