A Chinese edition of WordCraft: the complete source, buildable and changeable, with the layer Chinese writing actually needs added on top — national-standard layout for official documents, theses and legal papers, how Chinese characters are counted, and how fonts are written into the file the right way.

Upstream WordCraft is developed by the ArtCraft team (MIT OR Apache-2.0). This project is not ArtCraft, does not represent ArtCraft, and uses no ArtCraft marks; it says in plain text that it is based on WordCraft.

01What this is

Not a plugin, not a skin. One clone builds it; inside is WordCraft itself plus one Chinese layer.

Full source

Complete upstream source + patches

Divergence from upstream is two small patches, both inside small functions. Merging upstream stays easy; everything else is upstream as-is.

Counting

Chinese words counted by character

Chinese has no spaces to split on. A run of Chinese used to be tokenised on spaces and badly under-counted; it now follows Word's Chinese word count (G2).

Fonts & language

East Asian fonts and language marking

w:rFonts/@w:eastAsia and w:lang/@w:eastAsia round-trip correctly, so a Chinese document keeps its fonts and its language marking in Word.

Layout layer

National-standard skills and presets

Official documents (GB/T 9704), theses (GB/T 7713 and GB/T 7714 references) and legal papers: four skills, four presets, applied in one step. In the app: Home › 中文版式.

Fonts

A Chinese font, built in

The official binary embeds 阿里巴巴普惠体 (Alibaba PuHuiTi) as a fallback, so a machine with no Chinese fonts still shows Chinese instead of boxes. It never overrides a font the document asks for.

Offline

No network, no upload

No account, no cloud sync, no telemetry. Your writing stays on your machine.

Drivable

CLI, MCP, control channel

Every feature is a command. The ribbon, shortcuts, CLI and MCP dispatch through one registry, so an AI assistant can drive a document safely.

02The Chinese layout layer

Skills are operating manuals for AI assistants: which command to run when, what the standard requires, where the traps are. Each ships runnable scripts. They are layout only — the content must be final, and a skill will never write, invent or edit a word of it.

SkillWhat it doesStandard
gongwenOfficial documents: notices, requests, reports, letters, minutes, repliesGB/T 9704—2012
thesisTheses: title page, running head, contents, figure/table numbering, referencesGB/T 7713.1, GB/T 7714—2015
legal-docsCivil complaints, lawyer's letters, legal opinions, contract reviews, with an optional redacted versionlegal-document convention
wordcraftEvery WordCraft command, how to verify availability, and an evidence ledger—

Four sets of Chinese page setup and default styles live under presets/, each a runnable script: 

wordcraft-cli run --file draft.docx --script presets/zh-gongwen.json --save out.docx

03What changed relative to upstream

The baseline is upstream WordCraft v0.9.0.

Offered upstream · 1

Count Chinese characters as words

A run of Chinese used to be split on spaces and counted, badly under-counting it. It now follows Word's Chinese word count (G2), with numbers and characters counted too.

Offered upstream · 2

Read and write w:lang/@w:eastAsia

Chinese paragraphs used to lose their East Asian language marking, so Word would run its spell check in English.

This edition

Fixed the official-document font names

仿宋_GB2312 is not an installed family name on modern Windows, so asking for it made the renderer silently fall back to a sans face and lose the FangSong/Kai distinction. Names now resolve against what is actually installed.

This edition

Fixed the thesis script's command order

Inserting a header moves the caret into the header story, after which main-text-only commands fail. The contents and bibliography now come before footer and header.

This edition

Our own app icon

All ArtCraft art removed, replaced with a cinnabar rounded square and 文, generated as SVG / PNG / ICO / ICNS by one script.

This edition

A thin distribution

Crate names, the binary name wordcraft.exe, config directories and the bundle id are unchanged, so syncing with upstream stays cheap. Only the displayed name differs — window title, About box, the exe's properties, installer entries: about twenty-five lines in all.

Known limits, written down rather than hidden:

  • No Chinese spelling or grammar proofing. WordCraft proofs English, Russian, Polish, Portuguese and Italian only; this edition does not pretend otherwise.
  • The GB/T 7714 entry template has no issue-number slot, so a journal issue must be added by hand.
  • The bibliography heading defaults to the English References; pass title to references.bibliography to get 参考文献.
  • 方正小标宋简体 is not bundled with Windows, so a 公文 title falls back to a sans face and says so. The built-in PuHuiTi is a sans face too: it cannot replace 仿宋, 宋体 or 楷体, which still come from the system.
  • Traditional/Simplified conversion, pinyin sorting, and per-region default styles are not done yet.

04Try it

Build from source, then use the CLI, MCP, or the window itself.

git clone https://github.com/matou1118/TTWriter
cd TTWriter
cargo build --release -p wordcraft        # needs Rust 1.95+

wordcraft-cli convert draft.docx draft.pdf          # convert formats
wordcraft-cli render draft.docx page1.png --page 1  # render to an image
wordcraft-cli commands                              # list every command
wordcraft-cli mcp                                   # run as an MCP server for AI agents

05Relationship to upstream

This is a thin distribution: divergence is kept small and generic improvements go upstream as PRs. Both routes are welcome — generic problems belong upstream, Chinese-layer problems belong here.

Upstream licence unchanged

WordCraft itself stays MIT OR Apache-2.0. What this repository adds (skills, presets, tooling, docs) is Apache-2.0.

No upstream marks

All ArtCraft art removed; provenance stated in plain text. Assets are credited file by file in ATTRIBUTION.md.

Asset floor

Nothing is copied, traced or screenshot-cropped from Microsoft, Adobe, Avid or Autodesk — no icons, templates, themes or font data. National-standard layout is implemented from the published standards. The one font the official binary carries, 阿里巴巴普惠体 (Alibaba PuHuiTi), is Alibaba's own and is used as a fallback under its free-for-commercial-use licence; its files are not in this repository.

Credits

The ground everything stands on is the Rust word processor the ArtCraft team and WordCraft's contributors wrote from scratch. The Simplified Chinese interface comes from upstream.
