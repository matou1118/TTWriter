# GB/T 7714 参考文献著录速查

《信息与文献 参考文献著录规则》GB/T 7714—2015。
（更早的 GB/T 7714—2005 在中文期刊里仍常见，差异主要在电子资源与析出文献。）

---

## 著录方式

| 方式 | 正文标注 | 参考文献表 |
|---|---|---|
| **顺序编码制**（最常用） | `[1]` `[2]`，按首次引用顺序 | 按编号排列 |
| **著者-出版年制** | `张三(2021)` | 按著者字母/笔画顺序 |

国内高校学位论文多用**顺序编码制**。

---

## 文献类型标识

| 类型 | 标识 | 说明 |
|---|---|---|
| 专著 | `[M]` | 图书、手册 |
| 期刊文章 | `[J]` | 期刊论文 |
| 报纸文章 | `[N]` | 报纸 |
| 学位论文 | `[D]` | 硕士/博士论文 |
| 会议论文 | `[C]` | 会议录中的文章 |
| 论文集 | `[C]` | 会议录（整体） |
| 专著中的析出文献 | `[M]//` | 书中的章节 |
| 专利 | `[P]` | 专利说明书 |
| 标准 | `[S]` | 国家/行业标准 |
| 学位论文中的析出文献 | `[D]//` | 论文集中的文章 |
| 档案 | `[Z]` | |
| 数据集 | `[DS]` | |
| 电子资源 | `[EB/OL]` | 网上资源 |
| 计算机程序 | `[CP]` | |
| 其他 | `[Z]` | 未能归类的 |

## 各类著录格式

### 专著 `[M]`
```
主要责任者. 题名: 其他责任者. 版本项. 出版地: 出版者, 出版年: 引文页码〔文献类型标识〕.
```
```
[1] 张三, 李四. 共享空间研究[M]. 北京: 中国建筑工业出版社, 2021: 45-52.
[2] 交通银行. 金融风险评估[M]. 3版. 上海: 上海人民出版社, 2019.
```

### 期刊文章 `[J]`
```
主要责任者. 题名〔文献类型标识〕. 刊名, 年, 卷(期): 页码.
```
```
[3] 王五, 赵六. 城市社区公共空间研究[J]. 建筑学报, 2021, 3(2): 45-52.
[4] Smith J. Public space in cities[J]. Urban Design, 2020, 15(4): 112-129.
```

### 学位论文 `[D]`
```
主要责任者. 题名〔文献类型标识〕. 保存地: 保存者, 年份.
```
```
[5] 孙七. 共享空间使用行为研究[D]. 北京: 清华大学, 2022.
```

### 会议论文 `[C]`
```
主要责任者. 题名〔文献类型标识〕//论文集主要责任者. 论文集题名. 出版地: 出版者, 出版年: 页码.
```
```
[6] 周八. 装配式建筑技术[C]//中国建筑学会. 2021年装配式建筑学术会议论文集. 北京: 中国建筑工业出版社, 2021: 88-95.
```

### 专著中的析出文献 `[M]//`
```
析出文献主要责任者. 析出文献题名〔文献类型标识〕//专著主要责任者. 专著题名. 出版地: 出版者, 出版年: 页码.
```

### 专利 `[P]`
```
专利申请者. 专利题名: 专利号〔文献类型标识〕. 专利公布日期.
```
```
[7] 中国建筑科学研究院. 一种预制装配式墙板: CN105668291A[P]. 2016-02-24.
```

### 标准 `[S]`
```
主要责任者. 标准编号 标准名称〔文献类型标识〕. 出版地: 出版者, 出版年.
```
```
[8] 国家质量监督检验检疫总局, 中国国家标准化管理委员会. 党政机关公文格式: GB/T 9704—2012[S]. 北京: 中国标准出版社, 2012.
```

### 电子资源 `[EB/OL]`
```
主要责任者. 题名〔文献类型标识〕/主要责任者. 题名. (更新或修改日期)〔引用日期〕. 获取和访问路径.
```
```
[9] 国家法律法规数据库[EB/OL]. (2024-01-01)[2026-10-21]. https://flk.npc.gov.cn/.
```

### 报纸 `[N]`
```
主要责任者. 题名〔文献类型标识〕. 报纸名, 年-月-日(版次).
```

## 著录细则（最容易错的地方）

1. **责任者**：3 人以上用「等」/「, et al.」。**团体著者**直接写单位名。
2. **题名**：后不加句点，用「. 」分隔各项。
3. **期刊名**：不缩写，卷号后无空格，期号在圆括号内。
4. **页码**：起止页码，用「-」连接；不连续页要补起止（如 45-52, 105）。
5. **DOI**：可作为附注，也可单列。
6. **标点**：各项之间用「. 」，中文用全角「，」「：」「（）」，西文用半角。
7. **顺序编码制**下，正文引用角标**放在标点之后**（上标或方括号）。
8. **网络资源的引用日期**用方括号，格式 `[YYYY-MM-DD]`。
9. **中英文混排**：中文文献在前、英文在后（部分学校要求分开列）。
10. **GB/T 7714—2015 与 2005 的主要差别**：电子资源必须引用日期；
    析出文献的类型标识；专著版次；会议录的著录。

## 常见错误

| 错误 | 正确 |
|---|---|
| `[1]张三.共享空间研究[M].北京:中国建筑工业出版社,2021.` | 项间要有「. 」，中文用全角标点 |
| 期刊缺卷期 | `2021, 3(2): 45-52` |
| 页码写 `45-52.` 后面直接跟下一条 | 编号用 `[2]` 独立起行 |
| 三个以上作者全列 | 前三个 + 等/et al. |
| 电子资源无引用日期 | 必须有 `〔引用日期〕` |
| 会议论文类型码写成 `[C]` 但实际是会议录 | 会议录整体著录也是 `[C]`，析出文章按文章著录 |

## 在 WordCraft 里

```json
{ "command": "references.citation", "params": {
  "source": { "author": "张三", "title": "共享空间研究", "year": "2021",
              "journal": "建筑学报", "volume": "3", "issue": "2", "pages": "45-52" } } },
{ "command": "references.citationStyle", "params": { "style": "GB/T 7714" } },
{ "command": "references.bibliography", "params": {} }
```

**上游的引用实现是通用的**（12 种样式），GB/T 7714 的条目类型码、卷期页码、
标点细节**要逐条人工核对**。生成后渲染出来看一眼。

详见 [gbt7713.md](gbt7713.md) 的版面部分。
