# 法务文书排版

把**已定稿**的法务文书排成规范的 `.docx` / PDF。

## 文书速查（16 种，按场景路由）

| 场景 | 文书 |
|---|---|
| 起诉应诉 | 民事起诉状、民事答辩状、民事上诉状 |
| 财产与执行 | 财产保全申请书、强制执行申请书、撤诉申请书 |
| 日常民商 | **借条、欠条、收条**、催款函、和解协议 |
| 程序配套 | 授权委托书、法定代表人身份证明书、证据目录 |
| 劳动 | 劳动仲裁申请书、离职协议 |
| 非诉合同 | 房屋租赁合同、保密协议（NDA） |
| 律师输出 | 律师函、法律意见书、合同审查报告 |

每种文书的要素顺序与版式表见 [references/format.md](references/format.md)。

**边界说明**：合同**审查**（理解条款风险）需要法务内容层（WorkMind），本 skill 不做；合同**排版**（定稿后的格式）是纯版式层，做。

## 边界（重要）

| 层 | 负责 | 不负责 |
|---|---|---|
| **内容层**（法务 skill） | 法条检索、法律定性、风险清单、事实与证据梳理、文书起草 | 排版 |
| **本 skill（排版层）** | 字体、字号、段落、页码、标题层级、表格、签署区、脱敏标记、文件名 | **不改一个字的内容** |

**本 skill 不做的事**：
- 不检索法条、不引用法律、不做法律定性
- 不起草事实理由、不组织诉讼请求
- 不判断时效、不评估胜诉风险
- **不改写、不润色、不"完善"任何已经定稿的文字**

需要这些 → 交给内容层（见下方"与 WorkMind 配合"）。

## 铁律

1. **内容已定稿才排版。** 内容没定就排版，返工成本高。
2. **不补事实。** 缺当事人信息、缺日期、缺案号就留 `[待补充]`。
3. **脱敏规则由内容层决定，版式只负责落实。** 内容层标了要脱敏的字段
   （身份证、手机号、住址、账号），排版层负责**统一加标记**，不自己决定脱哪个。
4. **排完必须看。** 渲染成 PNG 并**真的打开看**——签署区位置、分页、
   证据清单表格的跨页在结构上看不出来。
5. **文件名有规范。** 见下。

## 常见文种的版式

### 民事起诉状

```
      民事起诉状
原告：（姓名/名称），（性别、出生年月���、民族、工作单位、职业），住（居）所，公民身份号码/统一社会信用代码，联系电话。
    法定代表人：（姓名），职务。
委托诉讼代理人：（姓名），（性别、出生年月、民族、工作单位、职业、职务），联系电话。
被告：（姓名/名称），（性别、出生年月、民族、工作单位、职业），住（居）所，公民身份号码/统一社会信用代码，联系电话。
案由：（案由）
诉讼请求
  1. ……
  2. ……
事实与理由
  ……
证据和证据来源
  1. 证据名称，证据来源，证明对象
  ……
此致
  人民法院
具状人：（签名/盖章）
（日期）
```

版式要点：
- 标题「民事起诉状」**黑体二号居中**
- 当事人信息**宋体小四**，每项一行
- 案由**加粗**，顶格
- 诉讼请求**用「1. 2. 3.」编号**，每项独立成段
- 事实与理由**宋体小四，首行缩进 2 字符**，行距 1.5 倍
- 证据清单用**三线表**（顶线、栏目线、底线，无竖线）
- 「此致」顶格，**「人民法院」另起一行左空二字**
- 具状人与日期**右对齐**（具状人右空二字，日期右空四字）
- 页码宋体小五居中

### 律师函

```
                ×××律师事务所
                  律师函
    ×××（抬头）：

    （正文）

    此致
    ×××（对方）

    ×××律师事务所
    承办律师：（姓名）  （执业证号）
    （日期）
```

版式要点：
- 律所名**黑体小二居中**（或加粗放大）
- 「律师函」**黑体二号居中**
- 抬头顶格
- 「此致」顶格，对方名称另起一行左空二字
- 落款右对齐

### 法律意见书

```
              法律意见书
    （委托方名称）：

    一、出具说明
    二、事实摘要
    三、法律依据
    四、法律分析
    五、风险提示与时效
    六、结论与建议
    七、参考案例比对

    （律所名）
    （承办律师：姓名）
    （日期）
```

版式要点：
- 标题黑体二号居中
- 委托方顶格
- **七个一级标题用「一、」到「七、」，黑体三号顶格**
- 正文宋体小四，首行缩进 2 字符，行距 1.5 倍
- 法律依据部分**条文要独立成段并首行缩进**（便于核对）
- 落款右对齐

### 合同审查报告

```
          ×××合同审查报告
    （合同名称）/ 审查对象：×××

    一、合同基础概况
    二、风险清单
        风险等级 | 条款位置 | 风险描述 | 修改建议 | 依据
    三、整体总结
    四、附件：修改建议稿（对照表）
```

版式要点：
- 标题黑体二号居中
- 风险清单用**表格**，表头灰底（浅灰 30%），**跨页时重复标题行**
- 风险等级用**文字**（高/中/低）而不是只用颜色——打印后仍可读
- 依据列放法条引用，**首行不缩进**

## 脱敏

内容层决定**脱敏哪些字段**，排版层负责**统一呈现**：

| 版本 | 用途 | 做法 |
|---|---|---|
| **内部完整版** | 存档、内部流转 | 全部信息，页眉不标注 |
| **对外脱敏版** | 发给对方、外部提交 | 按内容层标注逐项替换为 `张*`、`138****5678`、`××市××区` 等 |

**对外脱敏版**在页眉或页脚加一行标注：

```
【对外脱敏版本，内部底稿保留完整主体信息】
```

用 `insert.header` 加，**不要**用图片。

> 脱敏规则本身（保留几位、替换成什么）由内容层定义并执行；
> 本 skill 只负责**版式上的区分**（标注行、页眉）。

## 文件命名

内容层给定文种与主体，排版层按规范命名：

```
{文种}-{原告/委托方}诉{被告}.docx          起诉状
{文种}-{合同名}-{版本}.docx                律师函、审查报告
{文种}-{领域}-{委托方}.docx                法律意见书
{文种}-{主体}-{日期}.docx
```

日期用 `YYYYMMDD`。**内部版和对外脱敏版要能区分**（如加 `-内部` / `-对外` 后缀）。

## 与 WorkMind 配合

本机的 `D:\App\WorkMind` 是一套完整的法务内容层（MIT）：
72 部法条离线库、五步法律咨询、11 类要素式起诉状、16 领域法律意见书、
合同审查 8 模块、脱敏、时效自动计算、Logic Doctor 自检。

**它的渲染环节目前用 `python-docx`**（`generate_complaint.py` / `generate_opinion.py`），
产出的 docx 没有样式继承、没有目录域、没有真实页码、没有东亚排版——
对要正式提交、对方会打印归档的文件是硬伤。

**接法（不动 WorkMind 的法条库与业务流程）**：

1. 内容层照旧跑：法条检索 → 定性 → 风险清单 → 文书定稿
2. **输出环节换成本 skill 的排版**：
   ```bash
   python skills/legal-docs/scripts/format_legal.py 诉状定稿.json -o 民事起诉状-张三诉李四.docx
   ```
3. 版式规则由本 skill 提供（本文的表格）
4. **WorkMind 的 `knowledge/` 不复制进本仓库**——它是独立项目的资产，授权和体积要单独确认

## 版面检查

**借条/欠条/收条用生成器，别手写**——参数进、合规文书出（九要素内置、大写金额自动算、超 LPR 四倍利率直接拒绝生成）：

```bash
python scripts/jietiao.py --kind jietiao -o 借条.docx \
    --lender 张三 --lender-id 110101198805052345 \
    --borrower 李四 --borrower-id 110101199001011234 \
    --amount 50000 --rate 8 --months 6 --purpose 经营周转
```

`--kind qiantiao`（欠条，加 `--reason 货款`）/ `--kind shoutiao`（收条，加 `--for 房租`）。

其余文书先自动体检（结构层规则，零 LLM），再人眼看 PNG：

```bash
python scripts/check_legal.py 借条.docx          # 文书类型识别 + 借条九要素 + 此致格式 + 落款
python scripts/check_legal.py 起诉状.docx        # 当事人栏、此致、落款
python scripts/check_legal.py 文书.docx --json   # 机器可读
```

借条九要素体检是硬价值：双方身份、金额大小写并存、利率上限（LPR 4 倍）、交付方式——**缺一项都可能败诉**，全部可程序化断言。

```bash
wordcraft-cli render out.docx page1.png --page 1
```

逐项核对：

- [ ] 标题黑体二号居中
- [ ] 正文宋体小四、首行缩进 2 字符、行距 1.5 倍
- [ ] 「此致」顶格，对方/法院名称另起一行左空二字
- [ ] 具状人/署名右对齐，日期右空四字
- [ ] 证据清单是三线表，跨页重复标题行
- [ ] 对外脱敏版有页眉标注
- [ ] 页码宋体小五居中
- [ ] 签名/盖章位置留白够
- [ ] 表格没有超出版心
- [ ] 标题没有跨页断行（尤其"民事起诉状"四个字不能被拆开）
