# 法务文书版式表

四类常见中文法务文书的版式。**具体要求以受理法院/委托方/律所的模板为准**，本表是通行做法。

---

## 通用

| 项 | 设置 |
|---|---|
| 纸张 | A4（210×297mm） |
| 边距 | 上 3.7cm / 下 3.5cm / 左 2.8cm / 右 2.6cm（与公文一致，便于归档装订） |
| 正文 | 宋体 / 西文 Times New Roman，小四（12pt） |
| 行距 | 1.5 倍（或固定值 22–28 磅，按受理机关要求） |
| 首行缩进 | 2 字符 |
| 标题 | 黑体二号（22pt）居中 |
| 一级标题「一、」 | 黑体三号（16pt）顶格 |
| 页码 | 宋体小五（9pt）居中 |
| 落款 | 右对齐；具状人右空二字，日期右空四字 |
| 「此致」 | 顶格；下一行（法院/对方）左空二字 |

## 民事起诉状

### 要素顺序

```
标题
原告信息
  姓名/名称、性别、出生年月、民族、工作单位、职业、住（居）所
  公民身份号码 / 统一社会信用代码、联系电话
法定代表人（企业原告）
委托诉讼代理人
被告信息
案由
诉讼请求
事实与理由
证据和证据来源
此致
人民法院
具状人：（签名/盖章）
（日期）
```

### 版式

| 要素 | 版式 |
|---|---|
| 标题 | 黑体二号居中，「民事起诉状」五字**不能跨页断开** |
| 当事人信息 | 宋体小四，每项一行，**顶格不缩进** |
| 案由 | 加粗，顶格 |
| 诉讼请求 | 「1. 2. 3.」编号，每项**独立成段**，首行缩进 2 字符 |
| 事实与理由 | 宋体小四，首行缩进 2 字符 |
| 证据和证据来源 | 用**三线表**：序号 / 证据名称 / 证据来源 / 证明对象 / 备注 |
| 「此致」 | 顶格 |
| 「人民法院」 | 另起一行，左空二字 |
| 具状人 | 右对齐（签名或盖章处留白） |
| 日期 | 右对齐，格式「2026年10月21日」 |

### 常见错误

| 错误 | 正确 |
|---|---|
| 「此致」和「人民法院」同一行 | 「此致」顶格，「人民法院」另起一行左空二字 |
| 诉讼请求写成一段 | 每项独立成段，便于法院逐项判准 |
| 日期用「2026.10.21」 | 用「2026年10月21日」 |
| 证据清单用全框表 | 三线表（无竖线） |
| 原告信息首行缩进 | 顶格 |

## 律师函

| 要素 | 版式 |
|---|---|
| 律所名称 | 黑体小二（18pt）居中，或加粗放大 |
| 「律师函」 | 黑体二号居中 |
| 抬头 | 顶格，「XXX：」 |
| 正文 | 宋体小四，首行缩进 2 字符，1.5 倍行距 |
| 期限要求 | 可加粗：「请贵司于收到本函之日起七日内……」 |
| 「此致」 | 顶格 |
| 对方名称 | 另起一行，左空二字 |
| 律所署名 | 右对齐 |
| 承办律师 | 右对齐，含执业证号 |
| 日期 | 右对齐 |

> ⚠️ 律师函**没有法律强制格式**，但受理机关往往有自己的模板。以对方模板为准。

## 法律意见书

### 七段结构

```
一、出具说明        法条来源、核验方式、案例比对状态
二、事实摘要        问卷必答题概要（脱敏）
三、法律依据        每条 =《法律》第X条"原文"（注明版本）
四、法律分析        定性 → 构成要件 → 法律效果 → 救济路径
五、风险提示与时效   时效速查表 + 证据/管辖/执行风险
六、结论与建议      初步结论（不承诺结果）+ 可执行步骤
七、参考案例比对     案号/法院/裁判规则
```

### 版式

| 要素 | 版式 |
|---|---|
| 标题 | 黑体二号居中 |
| 委托方 | 顶格，「（委托方名称）：」 |
| 一级标题 | 「一、」到「七、」，黑体三号顶格，**各起新段** |
| 正文 | 宋体小四，首行缩进 2 字符，1.5 倍行距 |
| 法律依据的条文 | **独立成段并首行缩进**，便于逐条核对 |
| 时效表 | 三线表 |
| 案例比对表 | 三线表，案号/法院/裁判要点 |
| 免责声明 | 正文末尾，楷体或小四，与正文分开一段 |
| 落款 | 律所名 + 承办律师 + 日期，右对齐 |

## 合同审查报告

| 要素 | 版式 |
|---|---|
| 标题 | 黑体二号居中 |
| 审查对象 | 顶格，「审查对象：XXX合同」 |
| 一级标题 | 「一、」「二、」「三、」，黑体三号顶格 |
| 风险清单 | 表格：风险等级 / 条款位置 / 风险描述 / 修改建议 / 依据 |
| 表头 | 灰底（约 30% 灰），**跨页重复**（`table.repeatHeader`） |
| 风险等级 | **用文字**（高/中/低），不要只用颜色——打印后仍要能读 |
| 依据列 | 法条引用，首行**不缩进** |
| 附件 | 修改建议对照表（左列原文、右列建议），三线表 |

## 民事答辩状

被诉方对起诉状的回应。要素顺序：

```
标题（民事答辩状）
答辩人信息（同起诉状当事人栏）
被答辩人（原告）信息
案由
答辩意见（一、二、三……）
此致
人民法院
答辩人：（签名/盖章）
（日期）
附：本答辩状副本 X 份；证据目录
```

版式：同起诉状（黑体二号标题、宋体小四正文、答辩意见用「一、」编号顶格加粗）。
**注意**：答辩针对起诉状的诉讼请求逐项回应——答辩意见的「一、」对齐原告的请求编号最清晰。

## 民事上诉状

一审判决不服的上诉。要素顺序：

```
标题（民事上诉状）
上诉人（原审原告/被告）信息
被上诉人信息
案由 + 原审法院与案号（（2026）×0102 民初×××号）
上诉请求
上诉理由
此致
××市中级人民法院（原审法院转呈）
上诉人：（签名/盖章）
（日期）
```

版式：同起诉状。**上诉状交给原审法院转呈**（此致写原审法院名，不是中院——常见错误）。

## 强制执行申请书

判决生效后对方不履行。要素顺序：

```
标题（强制执行申请书）
申请人信息
被申请人信息
执行依据（生效法律文书名称与案号）
申请执行事项（判决主文的内容 + 金额）
事实与理由（履行情况、拒不履行）
此致
人民法院
申请人：（签名/盖章）
（日期）
附：生效判决书复印件
```

```
标题（财产保全申请书）

请求事项（查封/扣押/冻结 ××财产，价值××元）
事实与理由 + 担保方式
此致
人民法院
申请人：（签名/盖章）
（日期）
```

## 借条（民间借贷）

**要素九件套**（最高法民间借贷司法解释的举证要求，缺一项都可能败诉）：

```
标题（借条）
借款人：姓名 + 身份证号（全文，不缩写）
出借人：姓名 + 身份证号
借款金额：大写（壹拾万元整）+ 小写（¥100,000.00），两处必须一致
借款用途（经营/消费——写「周转」不如写具体用途，涉赌债务无效）
借款期限：自 2026 年 10 月 22 日至 2027 年 4 月 21 日
利率：年利率 ×%（不得超过一年期 LPR 的 4 倍；不写视为无息）
交付方式：银行转账至 ××账户 / 现金（写明——现金无流水是败诉首因）
还款方式：到期一次性归还 / 分期（分期写明每期金额与日期）
借款人：（签名 + 按手印 + 写日期）
```

版式：
- 标题黑体小二居中，正文宋体小四，行距 1.5 倍
- **借款人签名处留 3 行空白**（签名+手印+日期）
- 一页纸排完；排不下说明要素太多该拆合同了
- 金额大写数字用**壹贰叁肆伍陆柒捌玖拾佰仟萬**（不用一二三——易涂改）

**check_legal.py 会程序化断言这九要素**（见 SKILL.md 体检节）。

## 欠条 / 收条

```
欠条：欠款人信息 + 金额（大小写）+ 欠款事由 + 还款日期 + 签名手印
收条：交款人 + 收款人 + 金额（大小写）+ 款项性质 + 签名
```

版式同借条。欠条与借条的区别：借条=借款关系，欠条=其他债务（货款、赔偿）的确认——**事由栏必须写清债务来源**。

## 催款函（律师催告函）

```
标题（催款函 / 关于××的律师函）
致：（债务人全称）
正文：债务事实（合同/借条依据）→ 拖欠情况 → 催告限期（于收函后 X 日内）→ 法律后果（诉讼、利息、律师费承担）
此致
××（对方）
××律师事务所
承办律师：（姓名 执业证号）
（日期）
```

版式：同律师函。**催告限期必须具体到日**（「尽快」无法律意义）。

## 和解协议

```
标题（和解协议）
甲方信息 / 乙方信息
鉴于条款（争议事实陈述）
协议条款：
  一、和解金额与支付方式
  二、支付期限（分期写明每期）
  三、双方义务（撤诉/解除保全/返还财物）
  四、违约责任（逾期一次性到期 + 违约金）
  五、争议解决（本协议签订地法院）
甲方（签名盖章）  乙方（签名盖章）
（日期两栏并排）
```

版式：条款用「一、二、」黑体三号顶格；**双方落款左右并排**（甲方左、乙方右）——用两栏表格或制表位，不要上下排。

## 授权委托书（诉讼）

```
标题（授权委托书）
委托人：姓名 身份证号
受托人：姓名 身份证号 + 律所 + 执业证号
委托事项：××一案（案号）的一审诉讼
委托权限（勾选）：
  □ 一般授权（代收文书、出庭）
  □ 特别授权（承认、放弃、变更诉讼请求，和解，提起上诉/反诉）
委托人：（签名）
（日期）
```

**特别授权必须逐项写明**（民诉法解释的明示要求），只写「全权代理」视为一般授权——立案窗口高频退件事由。

## 法定代表人身份证明书

```
标题（法定代表人身份证明书）
××同志（身份证号）在我单位任××职务，系我单位法定代表人，特此证明。
单位全称（盖章）
（日期）
```

半页纸；标题黑体小二，正文宋体小四，**单位盖章处留白 2 行**。

## 证据目录（证据清单）

```
标题（证据目录）
案号 + 当事人
编号 | 证据名称 | 证据来源 | 证明对象与内容 | 原件/复印件 | 页数
（每组证据一行；同类证据可合并编号）
提交人：（签名）
（日期）
```

版式：**三线表**（顶线、栏目线、底线）；表头行加粗；跨页**重复标题行**；「原件/复印件」列不能空——法院核对证据的原件要求是硬性的。

## 房屋租赁合同（定稿排版）

```
标题（房屋租赁合同）
出租方（甲方）信息 / 承租方（乙方）信息
一、房屋基本情况（坐落、面积、权属）
二、租赁期限与交付
三、租金与押金（金额大小写、支付日期、退还条件）
四、用途与维修责任
五、转租禁止/条件
六、合同解除情形
七、违约责任
八、争议解决
落款：甲方（签名盖章）乙方（签名盖章）并排
```

版式：条款黑体三号顶格编号；金额**大小写并存**；「落款并排」同和解协议。

## 劳动仲裁申请书

```
标题（劳动仲裁申请书）
申请人信息 / 被申请人（用人单位）信息
仲裁请求（补发工资 X 元、经济补偿金 X 元……逐项列金额）
事实与理由（入职时间、离职时间、欠薪事实）
此致
××市劳动人事争议仲裁委员会
申请人：（签名）
（日期）
附：证据清单、劳动合同复印件
```

**仲裁时效一年**（劳动争议调解仲裁法第 27 条），从知道权利被侵害起算——事实与理由里写清这个时间点。

## 离职协议 / 保密协议（NDA）

离职协议要素：离职日期、补偿金额与支付、社保公积金截止、工作交接、保密与竞业条款（补偿标准）、放弃其他请求声明。

NDA 要素：保密信息定义、保密义务范围、期限、例外情形（公知、自行开发、法定披露）、违约金。

版式同通用合同：条款编号顶格、落款并排。

## 法院/仲裁文书的分页要求

- 标题、落款、签名**不能单独落在最后一页**（孤行）
- 证据清单表格跨页时**重复标题行**
- 页码连续，**首页也要有**
- 预留签名盖章位置（一般 2–3 行空白）
