# 法务文书版式表

四类常见中文法务文书的版式。**具体要求以受理法院/委托方/律所的模板为准**，本表是通行做法。

---

## 通用

| 项 | 设置 |
|---|---|
| 纸张 | A4（210×297mm） |
| 边距 | 上 3.7cm / 下 3.5cm / 左 2.8cm / 右 2.6cm（与公文一致，便于归档装订） |
| 正文 | 宋体 / 西文 Times New Roman，小四（12pt） |
| 行距 | 1.5 倍（或固定值 22–28 磅，按受理机关要求） |
| 首行缩进 | 2 字符 |
| 标题 | 黑体二号（22pt）居中 |
| 一级标题「一、」 | 黑体三号（16pt）顶格 |
| 页码 | 宋体小五（9pt）居中 |
| 落款 | 右对齐；具状人右空二字，日期右空四字 |
| 「此致」 | 顶格；下一行（法院/对方）左空二字 |

## 民事起诉状

### 要素顺序

```
标题
原告信息
  姓名/名称、性别、出生年月、民族、工作单位、职业、住（居）所
  公民身份号码 / 统一社会信用代码、联系电话
法定代表人（企业原告）
委托诉讼代理人
被告信息
案由
诉讼请求
事实与理由
证据和证据来源
此致
人民法院
具状人：（签名/盖章）
（日期）
```

### 版式

| 要素 | 版式 |
|---|---|
| 标题 | 黑体二号居中，「民事起诉状」五字**不能跨页断开** |
| 当事人信息 | 宋体小四，每项一行，**顶格不缩进** |
| 案由 | 加粗，顶格 |
| 诉讼请求 | 「1. 2. 3.」编号，每项**独立成段**，首行缩进 2 字符 |
| 事实与理由 | 宋体小四，首行缩进 2 字符 |
| 证据和证据来源 | 用**三线表**：序号 / 证据名称 / 证据来源 / 证明对象 / 备注 |
| 「此致」 | 顶格 |
| 「人民法院」 | 另起一行，左空二字 |
| 具状人 | 右对齐（签名或盖章处留白） |
| 日期 | 右对齐，格式「2026年10月21日」 |

### 常见错误

| 错误 | 正确 |
|---|---|
| 「此致」和「人民法院」同一行 | 「此致」顶格，「人民法院」另起一行左空二字 |
| 诉讼请求写成一段 | 每项独立成段，便于法院逐项判准 |
| 日期用「2026.10.21」 | 用「2026年10月21日」 |
| 证据清单用全框表 | 三线表（无竖线） |
| 原告信息首行缩进 | 顶格 |

## 律师函

| 要素 | 版式 |
|---|---|
| 律所名称 | 黑体小二（18pt）居中，或加粗放大 |
| 「律师函」 | 黑体二号居中 |
| 抬头 | 顶格，「XXX：」 |
| 正文 | 宋体小四，首行缩进 2 字符，1.5 倍行距 |
| 期限要求 | 可加粗：「请贵司于收到本函之日起七日内……」 |
| 「此致」 | 顶格 |
| 对方名称 | 另起一行，左空二字 |
| 律所署名 | 右对齐 |
| 承办律师 | 右对齐，含执业证号 |
| 日期 | 右对齐 |

> ⚠️ 律师函**没有法律强制格式**，但受理机关往往有自己的模板。以对方模板为准。

## 法律意见书

### 七段结构

```
一、出具说明        法条来源、核验方式、案例比对状态
二、事实摘要        问卷必答题概要（脱敏）
三、法律依据        每条 =《法律》第X条"原文"（注明版本）
四、法律分析        定性 → 构成要件 → 法律效果 → 救济路径
五、风险提示与时效   时效速查表 + 证据/管辖/执行风险
六、结论与建议      初步结论（不承诺结果）+ 可执行步骤
七、参考案例比对     案号/法院/裁判规则
```

### 版式

| 要素 | 版式 |
|---|---|
| 标题 | 黑体二号居中 |
| 委托方 | 顶格，「（委托方名称）：」 |
| 一级标题 | 「一、」到「七、」，黑体三号顶格，**各起新段** |
| 正文 | 宋体小四，首行缩进 2 字符，1.5 倍行距 |
| 法律依据的条文 | **独立成段并首行缩进**，便于逐条核对 |
| 时效表 | 三线表 |
| 案例比对表 | 三线表，案号/法院/裁判要点 |
| 免责声明 | 正文末尾，楷体或小四，与正文分开一段 |
| 落款 | 律所名 + 承办律师 + 日期，右对齐 |

## 合同审查报告

| 要素 | 版式 |
|---|---|
| 标题 | 黑体二号居中 |
| 审查对象 | 顶格，「审查对象：XXX合同」 |
| 一级标题 | 「一、」「二、」「三、」，黑体三号顶格 |
| 风险清单 | 表格：风险等级 / 条款位置 / 风险描述 / 修改建议 / 依据 |
| 表头 | 灰底（约 30% 灰），**跨页重复**（`table.repeatHeader`） |
| 风险等级 | **用文字**（高/中/低），不要只用颜色——打印后仍要能读 |
| 依据列 | 法条引用，首行**不缩进** |
| 附件 | 修改建议对照表（左列原文、右列建议），三线表 |

## 脱敏

| 字段 | 对外脱敏示例 |
|---|---|
| 姓名 | 张* / 李某某 |
| 身份证号 | 保留首尾各 1–2 位：3***********1234 |
| 手机号 | 保留前 3 后 4：138****5678 |
| 住址 | 保留到区/县：××市××区 |
| 银行账号 | 保留后 4：**** **** **** 6789 |
| 企业统一社会信用代码 | 保留首尾：91***********X |

**对外脱敏版**在页眉加一行：

```
【对外脱敏版本，内部底稿保留完整主体信息】
```

用 `insert.header`（宋体小五居中），**不要用图片**。

文件名区分：`xxx-起诉状-张三诉李四-对外.docx` / `-内部.docx`。

## 法院/仲裁文书的分页要求

- 标题、落款、签名**不能单独落在最后一页**（孤行）
- 证据清单表格跨页时**重复标题行**
- 页码连续，**首页也要有**
- 预留签名盖章位置（一般 2–3 行空白）
