# GB/T 9704—2012 速查

《党政机关公文格式》GB/T 9704—2012（现行）。标准全文：
<https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=F3CC9BEF482524C895FDA7A08BB4A70E>

> **按标准实现是合法的；不要抄 WPS 或 Word 的模板文件**——那是别人的著作权内容。

---

## 页面

A4（210mm × 297mm）。版心 **156mm × 225mm**。

| 边 | 标准 | 毫米 | 磅 | twips |
|---|---|---|---|---|
| 上白边 | 37mm ± 1mm | 37 | 104.9 | 2098 |
| 下白边 | 35mm ± 1mm | 35 | 99.2 | 1984 |
| 左白边（订口） | 28mm ± 1mm | 28 | 79.4 | 1588 |
| 右白边 | 26mm ± 1mm | 26 | 73.7 | 1474 |

**每面 22 行、每行 28 字** → 行距固定值 **28 磅**（225mm ÷ 22 行 ≈ 28pt）。

页码距版心下边缘 **7mm**（约 19.8 磅）。

## 数字与标点

- 发文字号年份用**六角括号**「〔〕」，发文机关代字和顺序号用阿拉伯数字
- 成文日期用**阿拉伯数字**（2012年7月1日），不用「二〇一二年」
- 金额、计量、序数、百分数用**阿拉伯数字**
- 成文日期中的「月」「日」不编虚位（1 日写「1 日」，不写「01 日」）
- 公文中的数字用法参照 GB/T 15835《出版物上数字用法》

## 行数校验

版心 225mm、行距 28 磅 → 每面 22 行。宽度 156mm、3 号字（16pt ≈ 5.64mm）→
每行约 28 字（扣除标点挤压与中西文间距的浮动）。

自查：

```bash
wordcraft-cli info gongwen.docx     # pages / words
wordcraft-cli render gongwen.docx page1.png --page 1
```

**看渲染图数行数**——`info` 不报行数，`render` 才看得出来。

## 字体可得性

| 字体 | Windows 自带？ | 文件 |
|---|---|---|
| 仿宋_GB2312 | 是 | `simfang.ttf` |
| 黑体 | 是 | `simhei.ttf` |
| 楷体_GB2312 | 是 | `simkai.ttf` |
| 宋体 | 是 | `simsun.ttc` |
| **方正小标宋简体** | **否** | 需自行安装 |

`fontEa` 只对**已安装**的字体生效，缺字体时静默回退。
`scripts/format_gongwen.py` 会检查字体文件是否存在并回退到黑体，同时给出提示。
